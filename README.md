# Box Model + Flexbox

Projeto didático de HTML e CSS para demonstrar o funcionamento do **Box Model** e de propriedades do **Flexbox**. A página apresenta 20 caixas com dimensões e estilos variados para facilitar a observação de como conteúdo, espaçamento, bordas e margens afetam cada elemento.

## Conteúdo

- Cabeçalho com navegação e identificação SENAI.
- Grade flexível com 20 caixas estilizadas individualmente.
- Exemplos de `content`, `padding`, `border` e `margin`.
- Demonstrações de propriedades Flexbox, como `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `gap`, `order` e `align-self`.
- Ajustes responsivos para telas menores.
- Redução de animações quando a preferência do sistema está ativada.

## Tecnologias

- HTML5
- CSS3

O projeto não requer dependências ou processo de compilação.

## Como executar

Abra o arquivo `index.html` diretamente em um navegador. O arquivo carrega `style.css` para aplicar os estilos.

## Estrutura

```text
.
├── index.html   # Estrutura da página e as 20 caixas
├── style.css    # Layout, Box Model, Flexbox e responsividade
└── README.md    # Documentação do projeto
```
